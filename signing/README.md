## Upload to Maven Central

1. Open https://central.sonatype.com/account
2. Go to **Signing Keys** (or **GPG Keys**)
3. Upload `oksp-maven-public.asc` from this directory
4. Wait for validation, then publish with the new key

Private key and passphrase are stored locally in `~/.gradle/gradle.properties` only.
